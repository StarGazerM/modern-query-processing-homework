# AI-use disclosure

Complete this short record for each submitted release. Delete the instructional
text and write `None` for any section that does not apply. Prompt transcripts
are not required. This record is evidence of verification, not a penalty for
using AI.

## Tools

List the AI tools or models that materially assisted the release.

## Material assistance

Summarize the code, tests, debugging, explanations, or writing for which they
provided material help.

## Verification

State how you checked that the submitted work is correct and that you can
explain it. Include the focused and full commands you ran.

## Invariant

Name one source-to-target or execution property that the release must preserve.
Explain where the code establishes it and which test observes it.

## Adversarial case

Give one small input, query, or execution case that distinguishes the intended
implementation from a plausible wrong one. State the predicted and observed
result.

## Adjacent-stage trace

Name the two adjacent artifacts you inspected and summarize the exact fact
added, preserved, or erased at that boundary.

## AI correction or rejection

Record one materially incorrect, incomplete, or unnecessary AI suggestion and
the evidence used to correct or reject it. Write `None` only if no AI tool made
a material suggestion during the release.
